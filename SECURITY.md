# Security policy

This is an unofficial SDK for the Todoist Tasks API. It is not affiliated with Todoist or supported by Voxgig.

For a security concern, contact the repository owner through the [GitHub profile](https://github.com/ArushKhasru) and avoid posting credentials or exploit details in a public issue. For ordinary bugs, use the [issue tracker](https://github.com/ArushKhasru/todoist-tasks-sdk/issues).

This policy covers the TypeScript SDK in this repository.
